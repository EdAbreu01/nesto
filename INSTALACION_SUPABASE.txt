1. CREAR TABLAS
En Supabase abre el proyecto Nesto > SQL Editor > New query.
Abre NESTO_SUPABASE.sql en un editor de texto, copia TODO y pulsa Run.
El resultado final debe mostrar finance_settings, finance_months y
wealth_accounts, con rls_activo = true en las tres filas.
El SQL no crea usuarios ni importa datos anteriores.

2. CREAR TU USUARIO
Authentication > Users > Add user > Create new user.
Escribe tu correo y una contraseña para entrar en Nesto.
Confirma el correo mediante el mecanismo que muestre Supabase.
No necesitas compartir la contraseña con nadie.

3. URL DE LA APLICACIÓN
Authentication > URL Configuration:
Site URL: https://edabreu01.github.io/nesto/
Añade esa misma dirección a Redirect URLs si usarás correos de autenticación.
El login actual usa correo y contraseña.

4. ACTUALIZAR GITHUB
Descomprime este ZIP y sube todos los archivos a la raíz de main.
Conserva las carpetas finanzas e inversiones completas.
Hay archivos nuevos: config.js, wealth-store.js y cloud-shell.js.
Reemplaza index.html, exports.js y los HTML de ambas carpetas.
Pages continúa en main / (root). No subas el ZIP como sustituto de los archivos.

5. COMPROBAR
Abre https://edabreu01.github.io/nesto/ y recarga con Ctrl+F5.
Entra con el usuario creado en el paso 2.
Crea un registro de presupuesto y una cuenta de ahorro de prueba.
Espera a ver Guardado en la nube en cada área.
Recarga y verifica que permanezcan. Comprueba también en otro dispositivo.

QUÉ SE GUARDA
Finanzas e historial mensual: finance_settings y finance_months.
Metas: campos goals y goals_revision en finance_settings.
Ahorros, portafolios, inversiones, movimientos y tipo de cambio: wealth_accounts.
Cada usuario tiene sus propias filas mediante RLS.
El ahorro presupuestado no se agrega automáticamente al patrimonio.

CONTINUIDAD Y RESPALDOS
